Each example shows only the fields needed for its outcome. Add those fields to an existing resource; the example is not a complete configuration.

## Resource fragments

The JavaScript Object Notation (JSON) snippets show fields under `spec`. Keep their object and array structure when you add them to a resource. Add routes and rules to existing lists without overwriting unrelated entries. Where the schema offers alternative response choices, select only one.

Replace `<APP_FIREWALL_NAME>`, `<ORIGIN_POOL_NAME>`, and `<XC_NAMESPACE>` with resource names and the namespace in your environment.

## Response-body encoding

Encode the message as UTF-8 (8-bit Unicode Transformation Format), convert those bytes to Base64 with `=` padding, then prepend `string:///`. The prefix counts toward the field's length limit. Examples show exact encoded values; decoded previews display markup as code without executing it.

When customizing a challenge page, keep F5's verification script or CAPTCHA controls in place so visitors can complete it. The `request_id` template is part of the example error body.
