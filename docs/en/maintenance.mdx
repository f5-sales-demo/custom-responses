A direct response route can show a maintenance page without waiting for the origin. This example matches `/maintenance` and returns status `503`.

> **Visitor message:** Scheduled maintenance

The `direct_response_route` selects `/maintenance`; `route_direct_response` supplies the status and body. The route affects matching requests only. See [response-body encoding](../configuration-reference/#response-body-encoding) for the body placeholder.
