A route redirect sends a request to its new location. The destination application serves the response.

> **Visitor response:** A redirect status and a `Location` identifying the destination.

The existing `/old` route returns `302` to `/new`. For requests with a body, `/demo/temporary` uses `307` and `/demo/permanent` uses `308` to preserve the request method and payload. The temporary route retains query parameters; the permanent route removes them. Removing a query changes the destination data even though the method and body survive.

**Expected result:** A synthetic POST with `?sample=synthetic` reaches `/demo/echo` as POST with the same body. The `307` destination includes the query; the `308` destination has no query. Inspect the first status and `Location` before following, then compare the echo. An unrelated path still reaches the origin.
