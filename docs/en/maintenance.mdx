Return an unavailable-service message without forwarding the request to the application. Choose a direct response when you deliberately want matching requests to stop at the edge; this example selects `/maintenance` and returns `503`.

> **Visitor message:** Scheduled maintenance

## Direct route and matching body

The load balancer's `direct_response_route` selects `/maintenance`; `route_direct_response` sets the status and encoded body. The matching `more_option.custom_errors["503"]` mapping supplies the same body for this direct error status. Both fragments belong to the same load balancer. In the qualified example, the mapping is required for the intended page to appear.

## Confirm the maintenance response

**Verified live example:** [View the maintenance page](https://custom-responses.f5-sales-demo.com/maintenance).

**Expected result:** The selected path returns `503` with “Scheduled maintenance”; `/` returns the normal application response. Compare the body as well as the status. Only matching routes stop forwarding requests.
