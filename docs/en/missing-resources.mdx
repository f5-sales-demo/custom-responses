Choose `404` when an address is unknown and `410` when a resource was deliberately retired. These direct response routes produce the page at the edge without asking the application to generate it.

| Status | Meaning | Example message |
| --- | --- | --- |
| `404` | The requested resource is not found; the status does not say whether this is permanent. | Resource not found |
| `410` | The resource is intentionally gone and its removal is expected to be permanent. | Resource retired |
