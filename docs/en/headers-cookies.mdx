Response transformations can add useful metadata and remove origin values that callers should not receive.

> **Visitor response:** `x-showcase: custom-responses` and a `showcase=custom-responses` cookie, without `x-origin-remove` or `origin-remove`.

The load balancer's `more_option` owns the add and remove lists. The added header uses `append: false`. The cookie has path `/`, Secure, HttpOnly, SameSite Lax, and `overwrite: true`. Check name collisions before overwriting origin values. A transformed cookie does not create an authenticated application session.
