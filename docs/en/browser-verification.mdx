A JavaScript challenge checks the browser before it reaches the application. The custom page explains the pause while F5 Distributed Cloud performs verification.

> **Visitor message:** Please wait while your browser is verified.

The load balancer's `js_challenge.custom_page` supplies the message. `cookie_expiry` is `300` seconds and `js_script_delay` is `1000` milliseconds in this example. Keep platform-controlled scripts working when changing the page; an accepted cookie changes what a returning visitor sees.

This challenge choice is unconditional: `/challenge` is a test path, not a selector. For a selected path, see [conditional challenges](../conditional-challenges/). See [response-body encoding](../configuration-reference/#response-body-encoding) for the body placeholder.
