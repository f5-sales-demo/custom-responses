A direct response route returns “Request received” at `/acknowledgement` with status `200`. The application does not process that request.

> **Visitor message:** Request received

In the load balancer's `routes` list, `direct_response_route` matches the path and `route_direct_response` defines the status and body. See [response-body encoding](../configuration-reference/#response-body-encoding) to create your own message.

This message confirms only that the route responded. It does not validate a submission, save data, or prove backend processing. If callers need a unique receipt or processing status, let the application provide it.
