A human-verification challenge asks visitors to complete a task before reaching the application. CAPTCHA stands for “Completely Automated Public Turing test to tell Computers and Humans Apart.” Use the custom page to explain what to do.

> **Visitor message:** Please complete the verification to continue.

The load balancer's `captcha_challenge.custom_page` supplies the wording; `cookie_expiry` is `300` seconds in this example. Keep the CAPTCHA controls usable when customizing the page. A returning visitor with an accepted cookie may not see the challenge again.

This setting is not restricted to `/challenge`; that path is only a test URL. To challenge selected paths, see [conditional challenges](../conditional-challenges/). See [response-body encoding](../configuration-reference/#response-body-encoding) to create your own message.
