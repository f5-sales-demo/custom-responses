A direct response route answers `/acknowledgement` with status `200` without contacting the origin.

> **Visitor message:** Request received

The `direct_response_route` selects the path, and `route_direct_response` supplies the status and body. See [response-body encoding](../configuration-reference/#response-body-encoding) for the body placeholder.

A static acknowledgement does not validate a submission, persist data, or prove backend processing. Use an application response when callers need a unique receipt or processing status.
