Return a fixed reply when application processing is unnecessary. This direct response route returns “Request received” at `/acknowledgement` with status `200`.

**Limit:** “Request received” does not prove submission validation, storage, or processing. If callers need a unique receipt or processing status, let the application provide it.

> **Visitor message:** Request received

In the load balancer's `routes` list, `direct_response_route` matches the path and `route_direct_response` defines the status and body.
