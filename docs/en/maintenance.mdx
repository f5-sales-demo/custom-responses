A direct response route serves a fixed message at `/maintenance` without forwarding the request to the application. This example returns status `503`.

> **Visitor message:** Scheduled maintenance

In the load balancer's `routes` list, `direct_response_route` matches `/maintenance` and `route_direct_response` defines the status and body. Other paths continue to the application. See [response-body encoding](../configuration-reference/#response-body-encoding) to create your own message.
