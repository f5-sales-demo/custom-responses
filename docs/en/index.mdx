Give visitors a useful explanation when an application fails, a security rule intervenes, or a resource moves. F5 Distributed Cloud lets you customize the message, status, redirect, headers, cookies, or selected response data. Choose the outcome below, then use its configuration example and focused comparison check.

The response mechanism determines when your message appears. Error maps replace eligible error bodies; direct routes answer selected paths; security engines customize their own blocking or challenge responses. Response transformations adjust traffic returned by an origin. Each page explains the distinction where you need it.

Examples come from the repository's Terraform JavaScript Object Notation (JSON) configuration. Readable body previews show the configured content; they do not establish that every demo endpoint is available. Expected behavior still needs a check in your authorized environment. Bot examples are explicitly configuration-only.

Use the [configuration reference](./configuration-reference/) to find complete source and repository operator instructions. No infrastructure changes are needed to read this guide.
