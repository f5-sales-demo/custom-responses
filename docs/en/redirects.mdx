A route redirect sends requests for `/old` to `/new` using `https`. The destination application serves the page.

> **Visitor response:** `302` with a `Location` ending in `/new`.

The `redirect_route` matches `/old`. Its `route_redirect` sets the protocol to `https`, the path to `/new`, and the status to `302` for temporary movement. Check how your clients handle request methods, and avoid a loop back to `/old`.
