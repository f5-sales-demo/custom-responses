A web application firewall (WAF) decides when to block a request. Configure `blocking_page` on the application firewall, then attach that firewall to the load balancer through `app_firewall`. Use a firewall in blocking mode and an authorized test request that triggers a rule.

Use Hypertext Markup Language (HTML) for browser pages or JavaScript Object Notation (JSON) for application clients.

The encoded `blocking_page` value has a 4,096-character limit including the prefix. See [response-body encoding](../configuration-reference/#response-body-encoding) to create your own message.

## HTML blocking page

> **Visitor message:** Request not accepted

Set `blocking_page.response_code` to `Forbidden` and put the HTML message in `blocking_page.blocking_page`.


**Expected result:** A blocked request returns `403` with the readable page; a benign request still reaches the origin. Check the firewall event: a `403` response alone does not prove the WAF made the block decision.
