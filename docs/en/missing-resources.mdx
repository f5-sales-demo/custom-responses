Give visitors a useful page while preserving the meaning of the HTTP status. A missing address returns `404`; a resource deliberately retired returns `410`.

> **Visitor response:** A branded “Resource not found” or “Resource retired” page.

Each `direct_response_route` selects exactly one path and returns its configured status and encoded HTML. The origin does not produce these pages. XC also needs matching load-balancer error bodies for `404` and `410`; without those mappings, these direct error statuses returned generic edge pages. This differs from an error mapping that may apply only to particular edge failures.
