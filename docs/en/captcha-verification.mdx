A CAPTCHA asks a visitor to complete a human-verification interaction before reaching the application. The custom page explains what to do.

> **Visitor message:** Please complete the verification to continue.

The load balancer's `captcha_challenge.custom_page` supplies the wording; `cookie_expiry` is `300` seconds in this example. Keep the platform-controlled interaction working when changing the page. An accepted cookie changes the returning visitor's experience.

This challenge choice is unconditional: `/challenge` is a test path, not a selector. For a selected path, see [conditional challenges](../conditional-challenges/). See [response-body encoding](../configuration-reference/#response-body-encoding) for the body placeholder.
