Help visitors understand why they see a verification page before your application. F5 Distributed Cloud supplies JavaScript browser verification; your custom wording explains the brief pause.

## Prerequisites

An F5 Distributed Cloud Hypertext Transfer Protocol (HTTP) load balancer is the resource that receives application requests and selects routing or security behavior.

You need permission to edit an existing HTTP load balancer in its namespace and a test application you are authorized to configure. Your environment must support the chosen challenge. Use a browser that can execute JavaScript. Allow about 10–15 minutes for configuration, excluding provisioning and security-event testing.

## Configure

### Customize the verification message

> **Visitor message:** Please wait while your browser is verified.

Keep the platform-controlled scripts working when you change the message. This load-balancer choice is unconditional: `/challenge` is a test path, not a path selector. For selected paths, use [conditional challenges](../conditional-challenges/).

1. Save the previous settings for the fields you change.
2. Set the load balancer's `js_challenge.custom_page` to the encoded message.
3. Set `cookie_expiry` to `300` seconds.
4. Set `js_script_delay` to `1000` milliseconds.
5. Save the load balancer.

Replace `<ENCODED_RESPONSE_BODY>` with your encoded message. See [response-body encoding](../configuration-reference/#response-body-encoding).

## Verify

1. Open `/challenge` in a fresh browser session on your configured host.
2. Confirm the custom wording appears alongside working browser-verification scripts.
3. Complete verification.
4. Confirm navigation to the application.
5. Request the application with the accepted verification cookie.
6. Confirm the normal application response.

Clear the verification cookie to repeat the first-visit check. Inspect the interaction and completion rather than assuming a fixed challenge status.

## Clean up

Restore the previous load-balancer challenge choice and its message and parameters. Preserve shared security policies and the load balancer. Clear the test browser's challenge cookie before checking the restored experience.
