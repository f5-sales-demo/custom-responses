The load balancer can add headers and cookies to an application response and remove unwanted values before returning it to the client.

> **Visitor response:** `x-showcase: custom-responses` and a `showcase=custom-responses` cookie, without `x-origin-remove` or `origin-remove`.

Configure the add and remove lists under the load balancer's `more_option` field. The added header uses `append: false`. The cookie has path `/`, Secure, HttpOnly, SameSite Lax, and `overwrite: true`. Check name collisions before overwriting origin values. Adding a cookie here does not sign a user in.
